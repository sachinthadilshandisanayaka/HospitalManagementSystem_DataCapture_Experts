# Git Guide — Clinic Appointment API

This guide explains the branch structure, how to clone and run the project, and the basic git workflow for contributing.

---

## Repository

```
https://github.com/sachinthadilshandisanayaka/HospitalManagementSystem_DataCapture_Experts.git
```

---

## Branch Structure

```
master   ── stable baseline (GitHub default branch)
develop  ── active development branch (all code lives here)
```

| Branch | Purpose |
|---|---|
| `master` | Stable, clean baseline. Only receives merges from `develop` when a version is ready. |
| `develop` | All active development happens here. Pull this branch to get the latest code. |

---

## Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/sachinthadilshandisanayaka/HospitalManagementSystem_DataCapture_Experts.git
```

This creates a folder called `HospitalManagementSystem_DataCapture_Experts` on your machine.

```bash
cd HospitalManagementSystem_DataCapture_Experts
```

---

## Switch to the develop Branch

After cloning, git checks out `master` by default. Switch to `develop` to get all the code:

```bash
git checkout develop
```

Verify you are on the right branch:

```bash
git branch
```

Output should show:
```
* develop
  master
```

---

## Pull Latest Changes

If you already cloned the repo earlier and want to get the newest code:

```bash
git checkout develop
git pull origin develop
```

---

## Full Setup After Cloning

Once you are on the `develop` branch:

### 1. Start MongoDB (Docker required)

```bash
docker-compose up -d
```

### 2. Build the project

```bash
mvn clean package -DskipTests
```

### 3. Run the application

**From terminal:**
```bash
java -jar target/appointment-api-1.0.0.jar
```

**From IntelliJ:**
1. Open the project in IntelliJ
2. Go to **Run → Edit Configurations**
3. Select `ClinicAppointmentApplication`
4. Set **Active profiles** to `local`
5. Click **Run**

### 4. Verify it is working

```bash
curl -H "X-API-KEY: clinic-secret-key" http://localhost:8080/api/practitioners?page=0&size=10
```

Or open Swagger UI: http://localhost:8080/swagger-ui

## Common Git Commands

### Check which branch you are on
```bash
git branch
```

### See recent commits
```bash
git log --oneline -10
```

### See what files changed
```bash
git status
```

### See the full diff of changes
```bash
git diff
```

### Stage and commit your changes
```bash
git add <file>            # stage a specific file
git add .                 # stage all changed files
git commit -m "your message"
```

### Push your commits to GitHub
```bash
git push origin develop
```

### Discard local changes to a file (careful — cannot undo)
```bash
git checkout -- <file>
```

### Fetch and merge latest remote changes
```bash
git pull origin develop
```

## Files Not in the Repository

The following are intentionally excluded from git (listed in `.gitignore`):

| File | Reason |
|---|---|
| `.env` | Contains credentials — never commit secrets |
| `target/` | Compiled build output — regenerated by Maven |
| `*.class` | Compiled Java bytecode |
| `.idea/`, `*.iml` | IntelliJ project files — machine-specific |
| Assessment PDF and requirement text files | Internal assessment documents |
